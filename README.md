# Employee Management System (JavaFX)

A comprehensive and visually intuitive **Employee Management System** built using **JavaFX**. This desktop application was developed as a university lab project to simplify corporate administrative tasks such as tracking employee details, managing departmental tasks, filtering leave requests, and updating monthly payroll distributions.

## 🚀 Key Features

* **Dynamic Dashboard Overview:** Instant summary cards showcasing Total Employees, Total Departments, and Monthly Payroll calculations. It also provides structured analytical views for pending, approved, and rejected leave forms.
* **Employee Records Management:** Complete module to view detailed lists of staff members and a dedicated input form to securely add new employee credentials (ID auto-generation included).
* **Department Trackers:** View ongoing organizational tasks, operational descriptions, and insert newly deployed corporate departments seamlessly.
* **Leave Filtering System:** Real-time data filtration system allowing administrators to sort through leave logs based on *Approved*, *Pending*, and *Rejected* status matrices.
* **Interactive Payroll Management:** An integrated payroll panel tracking employee salaries with a direct inline **EDIT** functionality to manually alter and re-calculate financial sheets on the fly.
